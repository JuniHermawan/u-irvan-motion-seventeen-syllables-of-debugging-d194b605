A tiny Python program (standard library only) that writes one haiku about debugging — three lines in the 5-7-5 syllable shape — to `entry.txt`. The haiku was picked from 24 fresh candidates scored against the published judge brief: a concrete image (an error message that blames the wrong line) and a last line that turns it (the blamed line is the author's own).

## Run it

```sh
python3 main.py
```
